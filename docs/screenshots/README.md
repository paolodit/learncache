# Screenshots

Public screenshots should use local or sample data only.

Suggested files:

- `learncache-app.png`
- `learncache-extension-youtube.png`
- `capture.png`
- `mobile-capture.png`

Before committing screenshots, check that they do not show:

- Personal domains
- Real email addresses
- API keys, app passwords, session secrets, or extension tokens
- Private transcripts, notes, or source URLs
- Internal hosting provider or database details
