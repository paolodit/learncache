# Screenshots

Public screenshots should use local or sample data only.

Suggested files:

- `inbox.png`
- `item-detail.png`
- `capture.png`
- `mobile-capture.png`

Before committing screenshots, check that they do not show:

- Personal domains
- Real email addresses
- API keys or Clerk keys
- Private transcripts, notes, or source URLs
- Internal CapRover or database details
